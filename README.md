# 한칸제작소 — 배포 안내

이 저장소는 **설치 파일과 안내문만** 둡니다. 소스 코드는 비공개입니다.
설치 파일은 오른쪽 **Releases**에서 받습니다.

> **제품명이 웹툰공방에서 한칸제작소로 바뀌었습니다.** 프로그램 이름·바로가기·창 제목만 바뀌고,
> 파일 형식(`.wtg`)은 그대로입니다. 새 판을 처음 실행하면 이전 판이 쓰던 설정 폴더의 장면·자동
> 저장·변환 캐시를 새 폴더로 **복사**합니다(이전 폴더는 지우지 않고 그대로 둡니다).
>
> **받는 파일 이름도 바뀌었습니다(webtoon-gongbang → hankan-studio).** 프로그램 안 표시 이름은
> 계속 한칸제작소이고, 여는 파일(`.wtg`)도 그대로 호환됩니다 — 설치·실행 파일 이름만 영문
> 표기로 통일했습니다.

## 받을 파일

| 장비 | 파일 |
|---|---|
| 윈도우 10/11 (x64) | `hankan-studio-<버전>-win-x64.exe` |
| 맥 (Apple Silicon) | `hankan-studio-<버전>-mac-arm64.dmg` |

ARM 윈도우는 x64 설치 파일이 에뮬레이션으로 실행됩니다(변환 속도는 느립니다). 인텔 맥은 지원하지 않습니다.

## 설치

- **윈도우**: exe를 실행합니다. 설치 폴더를 고를 수 있습니다. SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누릅니다(서명 인증서 없음).
- **맥**: dmg를 열고 앱을 응용 프로그램 폴더로 끌어 놓습니다. 처음 한 번은 **우클릭 → 열기**로 실행합니다(공증 없음).

## 여는 파일

- `.skp` 스케치업 파일. **SketchUp 8, 2013~2026 형식을 스케치업 없이 직접 읽습니다** — 구버전 파일을 최신
  버전으로 다시 저장할 필요가 없습니다. 다만 2013~2020 구형식은 장면의 숨김·스타일·그림자 설정까지는 아직
  넘어오지 않습니다(형상·장면·카메라는 읽힙니다). 열리지 않는 파일(.skb 백업, 다른 3D 형식, 암호로 잠긴
  파일, 손상된 파일)은 시작 안내(첫 실행 시 뜨는 창)에 그대로 나열돼 있습니다.
- `.wtg` 한칸제작소 파일. 변환된 모델(형상·텍스처 포함)과 장면·카메라·광원·선 설정을 담고 있어 원본 SKP 없이도
  다시 변환하지 않고 바로 열립니다. **저장은 대화상자 없이** SKP가 있던 폴더에 같은 이름으로 조용히
  씁니다(다른 이름으로 저장은 **Ctrl+Shift+S**). 저장·이동 절차와 저장 범위는 아래 "저장과 파일
  옮기기" 참고.

## 저장과 파일 옮기기

- **저장(단축키 없음, 상단 "저장" 버튼)**: 첫 저장부터 대화상자가 뜨지 않습니다. SKP를 열어 작업했다면 그
  SKP와 같은 폴더에 같은 이름의 `.wtg`가 바로 생기고, 이미 연 `.wtg`가 있다면 그 파일을 조용히 덮어씁니다.
- **다른 이름으로 저장(Ctrl+Shift+S)**: 이때만 저장 위치를 고르는 대화상자가 뜹니다. 컷마다 다른 `.wtg`로
  나눠 보관하고 싶을 때 씁니다.
- **다른 PC로 옮기기**: `.wtg` 파일 하나만 복사하면 됩니다. 원본 SKP나 텍스처 폴더를 함께 옮길 필요가
  없습니다 — 변환된 형상과 텍스처가 이미 그 파일 안에 들어 있습니다.
- **버전·플랫폼 호환**: `.wtg`는 Windows·Mac에서 공통으로 쓰는 zip 파일(형상 데이터 + 설정 + 썸네일)이라
  같은 형식 버전을 지원하는 앱이면 만든 장비의 운영체제와 무관하게 열립니다. 다만 이 저장소가 배포하는 앱은
  **Windows(x64, ARM은 에뮬레이션)·Mac(Apple Silicon)만 지원하며 Intel Mac은 지원하지 않습니다** — 다른
  장비로 옮길 때도 이 조합 안에서만 실행 자체가 됩니다. 더 오래된 앱 버전으로 더 새 형식의 `.wtg`를 열면
  "더 새로운 버전의 한칸제작소 파일입니다. 프로그램을 업데이트하세요."라는 안내와 함께 열기를 거부합니다 —
  파일이 깨지거나 잘못 열리는 대신 분명한 오류로 막습니다.
- **저장되는 것(현재 빌드 기준)**: "장면 추가"로 만들어 둔 사용자 장면은 그 카메라·레이어 표시·개체
  이동·회전·크기·그림자 켬/끔까지 저장됩니다. 선 두께·앞뒷면 기본색·1인칭 걷기 설정(키·속도)·Ctrl+G로
  만든 그룹·Ctrl+C/V로 복제한 개체도 함께 저장됩니다. **장면으로 아직 저장하지 않은, 지금 화면에 보이는
  구도**(예: 원본 SketchUp 장면을 그대로 두고 카메라만 옮기거나 개체를 이동·선택한 상태)도 이제 "저장"
  버튼을 누르면 함께 담기고, 파일을 닫았다가 다시 열어도 그대로 돌아옵니다 — 굳이 "장면 추가"로 먼저
  이름 붙은 장면을 만들지 않아도 됩니다. 자동 저장(작업 중 몇 초마다 조용히 남기는 복구용 기록)도 같은
  내용을 담아 두므로, "저장" 버튼을 누르기 전에 앱이 닫혀도 다음에 열 때 조용한 복구 안내와 "되돌리기"로
  그 구도를 되살릴 수 있습니다.

## 패치 업데이트(재설치 없음)

정보 창에서 "업데이트 확인"을 눌렀을 때 설치 파일을 새로 받지 않아도 되는 작은 패치가 있으면
"패치 적용(재설치 없음)" 버튼이 함께 뜹니다. 누르면 자동으로 받아 무결성을 확인한 뒤 적용되고,
프로그램이 그 자리에서 새 버전으로 다시 시작합니다. 받은 파일이 손상됐거나 적용 후 프로그램이
제대로 뜨지 않으면 자동으로 이전 상태로 되돌아가며, 기존 파일은 그대로 남습니다.
이 패치는 정보 창의 런타임 표시(예: `런타임 0.2 (빌드 4311)`)에만 반영되고, 설치 파일 자체의
버전(예: v0.2.0)은 바뀌지 않습니다 — 설치 파일이 바뀌는 큰 업데이트는 지금처럼 이 페이지에서
새로 받아야 합니다. 버전 표기 규칙(제품 버전 0.2 · 빌드 번호)은 `docs/versioning.ko.md` 참고.

## 라이선스 고지

한칸제작소는 비공개 소프트웨어입니다. 아래 오픈소스 구성요소를 포함하며, 각 라이선스 원문은 설치 폴더 안(`resources/vendor`, `resources/python`, Electron의 `LICENSE.electron.txt`·`LICENSES.chromium.html`)에 그대로 들어 있습니다.

| 구성요소 | 라이선스 |
|---|---|
| OpenSKP 1.2.0 (SKP 읽기) | MIT |
| shapely 2.1.2 | BSD-3-Clause |
| GEOS (shapely가 쓰는 기하 엔진, 별도 DLL로 동적 링크) | LGPL-2.1 |
| trimesh 5.1.0 | MIT |
| defusedxml 0.7.1 | PSF-2.0 |
| NumPy 2.3.5 (OpenBLAS 포함) | BSD-3-Clause |
| Pillow 12.3.0 | MIT-CMU |
| Python 3.12 (python-build-standalone) | PSF-2.0 |
| Electron 38 / Chromium | MIT / BSD-3-Clause |
| ffmpeg (Chromium 동봉, 별도 DLL로 동적 링크) | LGPL-2.1 |
| Microsoft Visual C++ 런타임 | Microsoft 재배포 조건 |

LGPL 구성요소(GEOS, ffmpeg)는 별도 라이브러리 파일로 배포되므로 같은 이름의 파일로 교체할 수 있습니다. 소스는 각 프로젝트(https://libgeos.org, https://ffmpeg.org)에서 받을 수 있습니다.
